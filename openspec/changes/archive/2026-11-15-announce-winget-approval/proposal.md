## Why

The README tells people to run `winget install Source191.Cader`, but the first submission to winget-pkgs (microsoft/winget-pkgs#479528) is still waiting for Microsoft's review, so the command finds nothing yet. A visitor who tries it and fails may not come back.

## What Changes

- A striking notice at the very top of the README, under the title: a winget badge and a GitHub "Important" callout saying Cader is nearly here and waiting for winget approval, linking to the winget-pkgs pull request.
- It is removed by hand once that pull request merges.
- README only: no behaviour, spec or `Version` change.
