# Proposal

## Why

The README's getting-started animation (`assets\readme\new-session.gif`) shows only the wizard and a new row. Now that `winget install Source191.Cader` works (microsoft/winget-pkgs PR 479528), a newcomer's real first minute is longer: install, `cader setup-terminal`, pick the Cader profile, start a session, open its pull request, and find the sessions again after closing the terminal. The README says all of that in words but shows only the first step of it.

This change is the proposal only; it is applied once the winget package is live.

## What Changes

- **Install and setup stay as text:** `winget install Source191.Cader` and `cader setup-terminal` are copy-pasteable code blocks in the README's install and getting-started sections (they largely exist already; the change checks them against the live package and tightens them), not frames in a GIF.
- **A still of the Cader profiles:** one PNG, `assets\readme\profiles.png`, of Windows Terminal's new-tab menu listing the Cader and Cader session profiles that `setup-terminal` adds, made over a made-up profile list.
- **A longer hero animation:** `new-session.gif` grows from the wizard to about 15 to 20 seconds covering: starting a session with `n`, opening its pull request with the PR key (the row's PR column filled in from the scene), then the console after a "restart" with the same sessions still listed, resumed with Enter. It is regenerated by `tools\New-ReadmeScreenshot.ps1` from `tools\ReadmeScene`, still over the made-up Northwind scene.
- **An optional walkthrough video:** a single MP4 (or WebM) of the whole path from `winget install` to resuming, recorded by the owner on a real screen against a throwaway demo repository and a clean made-up profile list, uploaded as a GitHub attachment and linked from `docs\user-guide.md`. Claude cannot record the real desktop, so this part is the owner's; the change supplies the shot list and the checklist for keeping it free of personal data.
- **Docs that name the media:** `tools\ReadmeScene\README.md` and CONTRIBUTING's "when to remake the images" mention the new script and image.

Out of scope: any change to Cader's behaviour, multiple Claude accounts (a later change), macOS or Linux, hosting the video anywhere but a GitHub attachment, and real (non-Northwind) repositories, people or paths in any image.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. This is documentation and tooling; the change declares `skip_specs: true`.

## Impact

- **Files:** `README.md`, `docs\user-guide.md`, `assets\readme\new-session.gif` (replaced), `assets\readme\profiles.png` (new), `tools\ReadmeScene\new-session.keys`, `tools\ReadmeScene\scene.json` (a pull request on the new session), `tools\ReadmeScene\README.md`, `tools\New-ReadmeScreenshot.ps1`, CONTRIBUTING.
- **Possible ReadmeScene code:** a scripted "restart" step and a stub for the browser launch of the PR key, both untested wiring unless they hold a decision, in which case they get tests in `tools\ReadmeScene.Tests`.
- **Ordering:** `readme-front-page` is still in progress and edits the same README sections; apply this change after it archives.
- **Size:** the GIF must stay small enough for the README to load quickly (target under 1.5 MB, about twice today's 330 KB at most).
